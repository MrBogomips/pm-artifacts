# Definition of Done

## Requirements

- [ ] Structural tests pass: `bash tests/run-structural-tests.sh`
- [ ] Pull request merged into `main`
- [ ] A new or changed artifact type: version bumped in `plugin.json`, README skills table updated
- [ ] A new artifact type: sample validated by the user (visual gate in `AGENTS.md`)
- [ ] Nothing from `_reference/` in committed files, samples or published artifacts

## On Done

- Delete without asking: `out/**`
- Delete the session scratchpad without asking (screenshots, local trials, client-data conversions).
- Never touch: `_reference/`
